# 01: Партія над колодою

**What to build:** Партія перестає сама здобувати собі Вправи й починає
приймати готову колоду та довжину. Ззовні Гра не змінюється нічим: ті самі
десять Карток, той самий рахунок, та сама поведінка «крок у Гру — нова
Партія». Це підготовча зміна перед Іспитом, щоб обидва розділи грали одну
Партію, а не дві схожі.

Колода — це просто список елементів; Партія не знає, Вправи це чи Питання
Іспиту. Самооцінка лишається спільною: `grade(knew)` для Картки — вибір
Тренера, для Тесту згодом — чи збігся обраний варіант із правильним. Довжина
стає параметром; десять лишається типовою.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Партія будується з переданої колоди, а не з атласу
- [x] Довжина Партії задається викликачем, десять — типова
- [x] Гра працює точно як раніше: десять Вправ, рахунок, список помилок
- [x] Наявні тести Гри лишаються зеленими без змін у своїх очікуваннях
- [x] Партія над довільною колодою відтворювана з насіння, як і зараз
- [x] Перевірка на телефоні: Партія в Грі проходиться від початку до підсумку
