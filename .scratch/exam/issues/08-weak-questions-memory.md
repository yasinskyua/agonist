# 08: Пам'ять слабких Питань

**What to build:** Застосунок запам'ятовує результат останньої зустрічі з
кожним Питанням — «знав» або «не знав», — і дає кнопку «Повторити слабкі»:
Партія лише з тих Питань, які востаннє не далися. Працює однаково для Карток і
для Тесту.

Пам'ять живе в браузері, без акаунтів і без синхронізації між пристроями —
застосунок ніколи їх не мав. Дотик до пам'яті браузера може кинути (приватне
вікно, заблоковані дані сайту), тож заблокована пам'ять забирає прогрес, але не
ламає розділ.

Це те, що відрізняє підготовку за тиждень від гортання раз: Студент бачить, що
саме в нього слабке, і ганяє тільки це.

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] Результат кожного Питання зберігається після Картки й після відповіді в Тесті
- [ ] Кнопка «Повторити слабкі» будує Партію лише з Питань, які востаннє були «не знав»
- [ ] Правильна відповідь прибирає Питання зі слабких
- [ ] Порожній список слабких не дає зламаної Партії, а каже, що повторювати нема чого
- [ ] Прогрес переживає перезавантаження сторінки
- [ ] Заблокована пам'ять браузера не ламає розділ: він просто не пам'ятає
- [ ] Пам'ять тестується підробним сховищем, зокрема таким, що кидає на дотик
- [ ] Перевірка на телефоні: «не знав» у Партії з'являється в слабких, «знав» прибирає
