# 01: Атлас М'язів у репозиторії

**What to build:** Два SVG атласу Ryan Graves (фронт і бек) лежать у
репозиторії, їхня ліцензія зафіксована, і з них витягнуто повний перелік
ідентифікаторів М'язів. Після цього контент має на що посилатися, а всі
подальші тікети — стабільний словник анатомічних імен.

Це підготовчий тікет: користувацької поведінки він не дає, але без нього
жодна не можлива.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] Обидва SVG (фронт і бек) у репозиторії, відкриваються в браузері
- [ ] Перевірено, що файли не містять вбудованих растрів, тексту й залежностей від шрифтів
- [ ] Витягнуто повний перелік `id` М'язів з обох файлів у довідковий файл, придатний для читання людиною й скриптом
- [ ] Перелік показує, який `id` до якого виду належить (фронт / бек) і які мають парні сторони `_l` / `_r`
- [x] Рядок атрибуції (автор, ліцензія, посилання на неї) записаний у репозиторії
- [x] Зафіксовано, що ліцензію підтверджено безпосередньо на сторінці джерела

**2026-09-20, агент.** Тікет упирається в один крок, який агент виконати не

Не зроблено: самі `front.svg` і `back.svg`. Figma Community не віддає файл по
URL — його треба скопіювати в акаунт Figma й експортувати SVG руками. Створення
акаунта й дії в чужому акаунті — не для агента. Через це відкритими лишаються
перші чотири пункти: без файлів немає ні перевірки на растри/текст/шрифти, ні
переліку `id`.

Зроблено:

- `CREDITS.md` — атрибуція Ryan Graves / CC BY 4.0 з посиланням на текст
  ліцензії. Ліцензію перевірено сьогодні безпосередньо на сторінці Figma:
  рядок `Licensed under CC BY 4.0`, автор `Ryan Graves`. Дата й дослівний
  рядок зафіксовані у файлі.
- `assets/atlas/README.md` — кроки експорту для людини. Критичний крок —
  галочка **Include "id" attribute** у панелі Export: без неї Figma не запише
  латинські імена шарів, і словника М'язів не буде.
- `tools/atlas-ids.mjs` — перевіряє обидва SVG (растри, текст, шрифти,
  зовнішні посилання — помилка, не попередження) і генерує
  `assets/atlas/muscle-ids.json`: один запис на М'яз, з видами (`front`/`back`)
  і переліком елементів, де видно парність `_l`/`_r`. Режим `--check` падає,
  якщо перелік розійшовся з SVG.
- `tools/atlas-ids.test.mjs` — `node --test`, чотири перевірки на фікстурах.

**Чому JSON, а не таблиця в markdown:** пункт вимагає файл, придатний для
читання людиною й скриптом. Відформатований JSON читається обома, а друга
копія того самого факту в markdown розійшлася б із першою (спека, «Похідні
дані не зберігаються»).

Після експорту двох файлів `node tools/atlas-ids.mjs` закриває чотири
відкритих пункти одним запуском.
