# 02: Тапнув М'яз — побачив Вправи

**What to build:** Перший наскрізний зріз продукту. Тренер відкриває додаток,
бачить мапу тіла, тапає по М'язу — і отримує Вправи, які його навантажують,
згруповані за Роллю. Перемикає вид спереду / ззаду. Читає все українською або
англійською.

Контент на цьому етапі **насіннєвий**: близько п'яти Вправ, М'язи, яких вони
торкаються, і їхні М'язові групи. Повна Мапа Ролей — окремий тікет; цей
доводить, що ланцюг від JSON до підсвіченого М'яза працює.

Тікет свідомо великий: він тягне контент, модуль, тести й інтерфейс разом.
Розділити його не можна — жодна половина не дає поведінки, яку видно.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Три файли контенту (М'язи, М'язові групи, Вправи) у репозиторії, редаговані звичайним текстовим редактором
- [ ] Ідентифікатор М'яза в контенті збігається з `id` шляху в SVG атласу
- [ ] Білатеральні М'язи — один запис у контенті; підсвічуються обидві сторони
- [ ] Модуль-атлас відповідає на запити: списки М'язів, М'язових груп і Вправ; М'язи Вправи з Ролями; Вправи М'яза; Вправи М'язової групи
- [ ] Вправи М'яза й Вправи М'язової групи **виводяться** з ребра «Вправа → М'яз + Роль», а не зберігаються окремо
- [ ] Модуль перевіряє інваріанти: кожен ідентифікатор М'яза існує в SVG, у кожної Вправи рівно один Агоніст, кожна згадана М'язова група існує, немає Вправ без М'язів
- [ ] М'язи без жодної Вправи допустимі й на мапі не інтерактивні
- [ ] Тести на `node --test` покривають інваріанти й запити, працюють на справжньому контенті, без залежностей і без `package.json`
- [ ] Модуль імпортується і в браузері, і в Node без змін і без кроку збірки
- [ ] Мапа тіла вставлена інлайн у документ; тап по М'язу підсвічує його зміною `fill`
- [ ] Тап по М'язу показує його Вправи, згруповані за Роллю
- [ ] Перемикач виду спереду / ззаду працює
- [ ] Назва М'яза показана українською й латиною
- [ ] Інтерфейс має українську й англійську; усі рядки йдуть через пошук перекладу з першого рядка коду
- [ ] Зони натискання на мапі придатні для пальця, керування однією рукою
- [ ] Жодного фреймворку, жодного кроку збірки: що лежить у репозиторії, те й виконується
