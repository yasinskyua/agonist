# 04: Мапа тіла — тапнув М'яз, побачив Вправи

**What to build:** Перше, що видно очима. Тренер відкриває додаток, бачить
мапу тіла, тапає по М'язу — той підсвічується, і поряд з'являються Вправи, які
його навантажують, згруповані за Роллю. Сторінка М'яза показує назву й
однорядкову Функцію. Перемикач виду спереду / ззаду. Усе двома мовами.

Дві мови закладаються тут, з першого рядка інтерфейсу, а не додаються потім:
ретрофіт i18n дорожчий за вбудований одразу.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Мапа тіла вставлена інлайн у документ, щоб її шляхи були доступні скриптом
- [ ] Підсвічування — зміна `fill` за атрибутом (`[data-muscle~="soleus"]`), без canvas і без бібліотек
- [ ] Тап по М'язу підсвічує всі його шляхи, включно з обома сторонами
- [ ] Тап по М'язу показує його Вправи, згруповані за Роллю
- [ ] Сторінка М'яза показує українську назву; латина — там, де існує, поле може бути порожнім
- [ ] Сторінка М'яза показує однорядкову Функцію («приводить стегно, згинає гомілку»)
- [ ] Перемикач виду спереду / ззаду працює
- [ ] М'язи без Вправ на мапі не інтерактивні й візуально не запрошують до тапу
- [ ] Інтерфейс має українську й англійську; усі рядки йдуть через пошук перекладу з першого рядка коду
- [ ] Зони натискання придатні для пальця, керування однією рукою
- [ ] Зона тапу може бути грубішою за шлях підсвічування: палець влучає в область, підсвічується точний М'яз
- [ ] М'язи, заміряні в тікеті 02 як вужчі за 44 px, отримують укрупнену зону тапу
- [ ] Жодного фреймворку, жодного кроку збірки: що лежить у репозиторії, те й виконується
