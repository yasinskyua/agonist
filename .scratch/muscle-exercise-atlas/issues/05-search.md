# 05: Пошук

**What to build:** Тренер знаходить потрібне, не згадуючи, як воно називається
чужою мовою. Одне поле шукає М'язи українською й латиною, Вправи англійською,
і М'язові групи — бо про тренування думають саме групами: «спина», «ноги».
Знайдена М'язова група розгортається у свої М'язи, щоб від «спини» дійти до
конкретного ромбоподібного.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Пошук знаходить М'яз за українською назвою
- [ ] Пошук знаходить М'яз за латинською назвою
- [ ] Пошук знаходить Вправу за англійською назвою
- [ ] Пошук знаходить М'язову групу за її назвою
- [ ] Результат для М'язової групи дозволяє перейти до М'язів, які в неї входять
- [ ] Результати різних типів (М'яз / Вправа / М'язова група) візуально розрізняються
- [ ] Пошук нечутливий до регістру й до відсутніх діакритичних знаків
- [ ] Логіка пошуку живе в модулі-атласі й покрита тестами
- [ ] Обидві мови інтерфейсу працюють на цьому екрані
