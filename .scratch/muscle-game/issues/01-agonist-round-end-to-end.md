# 01: Наскрізна Партія — Режим «Хто Агоніст?»

**What to build:** Тренер тапає «▶ Гра» в шапці атласу, бачить плитки п'яти
Режимів (активний лише «Хто Агоніст?», решта позначені «скоро»), грає Партію з
десяти питань на повноекранному екрані й отримує підсумок. Кожне питання —
Вправа й чотири М'язи; треба вибрати Агоніста. Після відповіді мапа
показує Розподіл Ролей цієї Вправи кольорами Ролей атласу; під мапою — рядок
пояснення, яку Роль має вибраний М'яз у цій Вправі (або що він у ній не
працює), і кнопка «Далі». Так само після правильної відповіді, і екран того ж
розміру: самі питання не перемикаються, Тренер іде далі кнопкою.

Це тонкий наскрізний тікет: він закладає модуль Гри (без DOM, з тестами на
справжньому контенті), маршрут, екран Партії й підсумок, на які сядуть інші
Режими. Після нього вже можна зіграти на телефоні й відповісти, чи цікаво.

Екран — за вердиктом прототипу (гілка `prototype/muscle-game`,
`PROTOTYPE-VERDICT.md`): вхід з варіанта A, Партія з варіанта C без вкладок.
Деталі — у `../spec.md`, історії 1–15, 28–31, 40–46, 51–53.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] У шапці атласу є кнопка «Гра»; Гра має власну адресу, Back телефона з неї виходить, перезавантаження на ній відкриває вибір Режиму
- [x] Вибір Режиму — плитки п'яти Режимів з описом; неготові неактивні
- [x] Партія — рівно 10 питань без повторів; прогрес показує правильні й хибні; серія з'являється від двох поспіль
- [x] Варіанти — Агоніст і три М'язи, спершу Синергісти й Стабілізатори цієї Вправи, потім М'язи Групи Агоніста, потім будь-які; рівно одна правильна відповідь
- [x] Після відповіді «Детальніше» відкриває поверх мапи Функцію Агоніста й усі Ролі Вправи з поясненнями, нічого не зсуваючи
- [x] Після відповіді мапа показує Ролі Вправи й повернута на бік, де видно Агоніста; тап по мапі під час Гри не відкриває довідник
- [x] Після відповіді (правильної чи хибної) екран однаковий за розміром: позначка й слова (не лише колір), рядок «що цей М'яз тут», «Далі»; автопереходу немає
- [x] Підсумок: рахунок з 10, найдовша серія від трьох, унікальні помилки з посиланнями на Вправу; посилання виводить з Гри в довідник; «Ще раз», «Інший Режим», закрити
- [x] Закрити Гру можна будь-коли (і Forward після цього не повертає стару Партію); шторка й підказка атласу на час Гри сховані
- [x] Усі нові рядки інтерфейсу — обома мовами через словник; назви Вправ мовою інтерфейсу
- [x] Грається з клавіатури; результат відповіді озвучується скрінрідером
- [x] Модуль Гри покритий тестами на справжньому контенті з фіксованою випадковістю: 10 без повторів, одна правильна з чотирьох різних, порядок відволікаючих
- [x] Перевірено на телефоні: одна повна Партія до підсумку і перехід з помилки в довідник

## Comments

**21.09.2026, після кількох Партій на телефоні.** Власник зіграв і прийняв. За підсумками гри змінено:

- автопереходу немає — після будь-якої відповіді «Далі»;
- екран Партії сталий: шапка й панель однакової висоти для кожного питання, до відповіді й після, один кегль для всіх назв;
- відповідь наближає правильний М'яз, наступне питання — знову ціла фігура;
- «Детальніше» поверх мапи: Функція Агоніста, усі Ролі Вправи, пояснення автора;
- кнопки підсумку — під рахунком; мапа на сторінці Вправи з підсумку видна;
- правило непевних пар знято: у `main` вичитку закрито (тікет 10, ADR-0006).
