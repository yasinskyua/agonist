# 02: Пам'ять помилок

**What to build:** Гра пам'ятає, де Тренер помиляється, і частіше питає саме
це. Помилка робить елемент «слабким» у своєму Режимі (М'яз, Вправу чи пару
«Вправа + М'яз» — що питалось); дві правильні відповіді поспіль знімають
позначку. Партія бере до половини питань зі слабких цього Режиму, решту
випадково. Пам'ять живе на пристрої між візитами; заблоковане сховище
означає Гру без пам'яті, а не помилку.

Робиться для всіх Режимів одразу, тож Режими з тікетів 03–06 отримують її
без окремої роботи. Деталі — `../spec.md`, історії 47–50.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Слабкі займають до половини Партії; без повторів у Партії лишається правилом
- [ ] Пам'ять переживає перезавантаження сторінки
- [ ] Сховище, що кидає виняток, не ламає Гру — вона грається без пам'яті

- [ ] Покрито тестами модуля Гри: стає слабким, знімається, частіше потрапляє в Партію, заблоковане сховище
