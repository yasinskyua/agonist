# 06: Режим «Де Агоніст?»

**What to build:** Тренер бачить М'яз і вибирає з чотирьох Вправ ту, де цей
М'яз — Агоніст. Питання звучить саме так — «У якій Вправі X — Агоніст?», без
слова «навантажує» (у довіднику воно означає будь-яку Роль). Рівно одна
правильна: інші Вправи, де М'яз теж Агоніст, у варіанти не потрапляють.
Неправильні — спершу Вправи, де М'яз працює, але не Агоністом. Після помилки —
яку Роль М'яз має у вибраній Вправі.

Деталі — `../spec.md`, історії 36–39.
