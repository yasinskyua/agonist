# 01: Довідник із закріпленою мапою

**What to build:** Замість шторки поверх мапи — сторінки, що гортаються:
шапка («Agonist» — на головну, «Знав / Не знав», мова поки де є), на головній
пошук, під ним закріплена мапа з обома сторонами тіла, під мапою покажчик або
результати пошуку. Сторінки М'яза й Вправи — той самий каркас: заголовок,
закріплена мапа з їхніми кольорами, список. Внизу ліворуч «Назад», глибше —
«На головну». Маршрути в хеші ті самі, кожен крок — запис історії.

Еталон — `prototype/concepts` (останній коміт), але без масштабу,
підсвічування під час прокрутки й повноекранної мапи — вони в наступних
тікетах. Деталі — `../spec.md`, історії 1–8, 20–23, 33–34.

**Blocked by:** None (can start immediately)

**Status:** resolved
