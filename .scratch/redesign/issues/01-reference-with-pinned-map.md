# 01: Довідник із закріпленою мапою

**What to build:** Замість шторки поверх мапи — сторінки, що гортаються:
шапка («Agonist» — на головну, «Знав / Не знав», мова поки де є), на головній
пошук, під ним закріплена мапа з обома сторонами тіла, під мапою покажчик або
результати пошуку. Сторінки М'яза й Вправи — той самий каркас: заголовок,
закріплена мапа з їхніми кольорами, список. Внизу ліворуч «Назад», глибше —
«На головну». Маршрути в хеші ті самі, кожен крок — запис історії.

Еталон — `prototype/concepts` (останній коміт), але без масштабу,
підсвічування під час прокрутки й повноекранної мапи — вони в наступних
тікетах. Деталі — `../spec.md`, історії 1–8, 20–23, 33–34.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Шторка на трьох висотах і її детенти прибрані; кожен екран — сторінка з закріпленою (sticky) мапою
- [ ] Головна: пошук, мапа, покажчик М'язів за Групами з числом Вправ; пошук по М'язах, Групах, Вправах обома мовами й латиною
- [ ] Сторінка М'яза: назва, латина, Функція, Вправи з Роллю; сторінка Вправи: назва обома мовами, легенда, М'язи з Роллю й Поясненням, Пов'язані вправи
- [ ] Тап по М'язу на мапі й по рядку відкриває його сторінку; зони дотику для дрібних М'язів збережені; М'язи без Вправ не тапаються
- [ ] «Назад» внизу ліворуч, «На головну» поруч від двох кроків углиб; «Agonist» у шапці — на головну; Back телефона й свайп від краю працюють; після «На головну» Back не прокручує старі екрани
- [ ] Старі посилання `#/front`, `#/back`, `#/muscle/<id>`, `#/exercise/<id>` відкривають відповідні екрани
- [ ] Вигляд за прототипом: біле, чорне, один червоний; кнопки-іконки одного лінійного набору; усі цілі ≥ 44 px; кожна іконка має підпис для скрінрідера
- [ ] Усі нові рядки — обома мовами через словник
- [ ] Наявні тести зелені; перевірено на телефоні
