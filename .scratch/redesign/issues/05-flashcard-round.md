# 05: Гра — Картки «Знав / Не знав»

**What to build:** Замість Режимів і варіантів — Партія з десяти Карток. На
Картці Вправа й мапа без кольорів; «Показати відповідь» відкриває Агоніста,
Розподіл Ролей на мапі й список Ролей; Тренер ставить собі «Знав» чи «Не
знав». Підсумок: скільки знав з десяти й Вправи з «Не знав» з посиланнями.
Вихід — маленька ✕ унизу; з підсумку — «На мапу» й «Ще партія».

`quiz.mjs` переписується: Режими, варіанти й підбір відволікаючих М'язів
прибираються разом зі словниковими рядками й CSS старої Гри. ADR-0007.
Деталі — `../spec.md`, історії 24–29.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Гра відкривається з шапки за адресою `#/game`; перезавантаження на ній починає нову Партію
- [ ] 10 Карток без повторів; Картка — Вправа, мапа без кольорів, «Показати відповідь»
- [ ] Після показу: Агоніст, Ролі на мапі, список М'язів з Ролями; «Знав» / «Не знав»; тап по мапі нічого не відкриває
- [ ] Лічильник «N/10 · знав K» у шапці; підсумок — рахунок і Вправи з «Не знав» з посиланнями
- [ ] ✕ унизу виходить на головну; з підсумку — «На мапу», «Ще партія»
- [ ] Режими, варіанти, вибір Режиму й старий шар Гри прибрані з коду, словника й CSS
