# 01: Рядки М'язів і Вправ стають справжніми посиланнями

**What to build:** Кожен рядок М'яза чи Вправи (в індексі, результатах пошуку, картці М'яза, картці
Вправи, «Пов'язаних вправах») відкривається як посилання: у новій вкладці,
довгим натисканням можна скопіювати адресу, звичайне натискання веде туди, куди
вело досі. Для Тренера, який тримає кілька Вправ поруч, це різниця між
«одна вкладка» і «стільки, скільки треба».

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Рядок має адресу того екрана, який відкриває; Cmd/Ctrl-клік і середня кнопка відкривають нову вкладку без перехоплення
- [x] Звичайне натискання веде на той самий екран, з тим самим кроком історії, глибиною і збереженням положення шторки, що й раніше
- [x] Кнопка «Назад» у шторці й у браузері поводиться як до зміни; глибина кроків не порушена
- [ ] Рядок виглядає так само, як кнопка-рядок: колір, підкреслення, відступи, шеврон, стан натискання, фокус
- [ ] Пошук і індекс залишаються працездатними: знайдений рядок відкривається; клавіатура ховається, як і раніше
- [x] `node --test` дає ті самі 51 тест, усі зелені
- [ ] Перевірено на телефоні й у браузері: новий таб з рядка, довге натискання, Назад
