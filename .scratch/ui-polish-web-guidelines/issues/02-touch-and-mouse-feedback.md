# 02: Відгук на наведення, дотик і перетягування

**What to build:** Кнопки, піґулки, рядки й іконки реагують на наведення мишкою (Тренер за
ноутбуком бачить, що вони натискаються) і не залипають у наведеному стані на
дотик. На iOS зникає сірий спалах поверх власного відгуку рядка. Поки Тренер
тягне шторку пальцем, текст під нею не виділяється.

**Blocked by:** 01 (рядки-посилання: їхні стилі ще змінюються)

**Status:** resolved

- [x] Кнопки, піґулки, іконки, рядки й мовна кнопка мають помітний стан наведення, але лише на пристроях із наведенням
- [x] На дотик стан наведення не залипає після натискання
- [x] Стандартна підсвітка натискання iOS вимкнена; власний стан натискання рядка лишається єдиним відгуком
- [x] Під час перетягування шторки виділення тексту вимкнене й знову вмикається після відпускання
- [ ] Візуально на сенсорному екрані без наведення нічого не змінилось, крім зниклого спалаху
- [ ] Перевірено на телефоні (спалах, перетягування) і в браузері на ноутбуці (наведення)

## Comments

**Перевірка 21.09.2026.** Автоперевірка: hover-правила лежать у `@media (hover: hover)`; `-webkit-tap-highlight-color` прозорий; `user-select: none` під час `body.dragging`. Не перевірено: вигляд на дотик і сам спалах на iPhone.
