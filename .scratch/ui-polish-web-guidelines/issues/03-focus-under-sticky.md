# 03: Фокус клавіатурою не ховається під липкими рядками

**What to build:** Тренер, який ходить Tab-ом по прокрученому списку в шторці, завжди бачить
сфокусований рядок: браузер не ховає його під ручкою шторки, полем пошуку чи
першим рядком картки. Це вимога доступності, і вона ж помітна кожному, хто
користується зовнішньою клавіатурою з планшетом.

**Blocked by:** 01 (перевіряємо на посиланнях, а не на кнопках)

**Status:** resolved

- [ ] Прокрутивши список у шторці й натиснувши Tab, кожен наступний рядок повністю видно під липкими елементами
- [ ] Те саме для Shift+Tab у зворотний бік
- [ ] Працює в усіх трьох висотах шторки, на екрані карти (пошук) і в картці М'яза чи Вправи
- [ ] Вигляд шторки без фокуса не змінився
- [ ] Перевірено в браузері з клавіатурою: Tab з кінця довгого списку й назад

## Comments

**Перевірка 21.09.2026.** Автоперевірка: `scroll-padding-top` у шторці = 85.5 px. Поведінку Tab / Shift+Tab по довгому списку в трьох висотах шторки не перевіряла: лишається власникові.
