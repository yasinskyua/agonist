# 04: Кнопка ✕ картки має зону натискання не менше 44 px

**What to build:** Кнопка закриття картки виглядає так само, але в неї легше влучити пальцем: зона
натискання не менша за мінімум, який застосунок уже оголосив однією величиною
для пальця. Зараз вона близько 37 px, тобто менша за власну межу.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Зона натискання ✕ не менша за оголошений мінімум (44 px) в обох вимірах
- [ ] Візуальний розмір кружечка й позиція ✕ не змінилися
- [ ] Розширена зона не перекриває назву картки й не перехоплює натискання сусідів у заголовку
- [ ] Кнопка «Назад» і ✕ пошуку (вже 44 px) без змін
- [ ] Перевірено на телефоні: влучання ✕ великим пальцем однією рукою
