# 05: Горизонтальна орієнтація й розмір тексту за налаштуванням

**What to build:** Тренер тримає телефон горизонтально, і виріз чи скруглені кути не накривають
заголовок, поле пошуку й рядки. А розмір тексту застосунку слухається
налаштування «розмір тексту» в телефоні, тож Тренерові з поганим зором не
треба масштабувати сторінку.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] У горизонтальній орієнтації iPhone заголовок, кнопка мови, поле пошуку, картка й рядки не заходять під виріз чи скруглення; бічні безпечні зони враховані так само, як верхня й нижня
- [ ] У вертикальній орієнтації нічого не змінилося (бічні відступи нульові)
- [ ] Базовий розмір тексту задано відносно налаштування користувача; на типовому налаштуванні вигляд не змінився
- [ ] Збільшення тексту в налаштуваннях телефона збільшує текст застосунку без обрізань у шторці й заголовку
- [ ] Перевірено на телефоні в обох орієнтаціях і з трохи збільшеним розміром тексту
