# 06: Поле пошуку не втручається в слова Тренера

**What to build:** Тренер вводить скорочені запити («мязи задньоі», «прямии»), і клавіатура не
«виправляє» їх, не робить першу літеру великою й не підкреслює червоним.
Підказка в порожньому полі показує приклад і закінчується символом «…» обома
мовами.

**Blocked by:** None (can start immediately)
