# 07: Довгі назви читаються цілими

**What to build:** Довга назва Вправи чи М'яза («Великогомілковий м'яз», «Підтягування зворотним
хватом») не вилазить за межі картки й не залишає одне слово на другому рядку.
Латинські назви лишаються латинськими, коли Chrome пропонує перекласти сторінку.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Заголовок картки звужується й переносить довге слово, не виходячи за межі кнопок ‹ і ✕
- [x] Заголовки (картка, назви груп, підказка на карті) балансують перенесення без «вдови»
- [x] Латинські назви М'язів (рядок М'яза, картка М'яза, латинська форма другої назви Вправи) позначені як неперекладні й не змінюються автоперекладом Chrome
- [x] У низькій шторці заголовок картки лишається обрізаним до двох рядків, як зараз
- [x] Перевірено на вузькому екрані (320 px) з найдовшою назвою Вправи й М'яза

## Comments

**Перевірка 21.09.2026.** Автоперевірка: `translate="no"` на латинських назвах; `text-wrap: balance` на заголовку картки. Не перевірено: 320 px з найдовшими назвами, низька шторка на телефоні.

**Телефон, 21.09.2026.** Власник пройшов застосунок на телефоні після пушу: усе працює. Відповідні критерії відмічено.

**Екран 320 px (автоперевірка, 21.09.2026).** Найдовші назви: Вправа «Повороти тулуба сидячи (російський твіст)» і М'яз «Трапецієподібний м'яз, середня частина (середня трапеція)». У трьох висотах шторки й українською та англійською немає горизонтального переповнення шторки, сторінки чи заголовка; назва закінчується за 4 px до ✕, у низькій шторці її обрізано до двох рядків, у середній і високій вона йде на три рядки й повністю видна.
