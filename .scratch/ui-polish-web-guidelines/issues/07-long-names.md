# 07: Довгі назви читаються цілими

**What to build:** Довга назва Вправи чи М'яза («Великогомілковий м'яз», «Підтягування зворотним
хватом») не вилазить за межі картки й не залишає одне слово на другому рядку.
Латинські назви лишаються латинськими, коли Chrome пропонує перекласти сторінку.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Заголовок картки звужується й переносить довге слово, не виходячи за межі кнопок ‹ і ✕
- [ ] Заголовки (картка, назви груп, підказка на карті) балансують перенесення без «вдови»
- [ ] Латинські назви М'язів (рядок М'яза, картка М'яза, латинська форма другої назви Вправи) позначені як неперекладні й не змінюються автоперекладом Chrome
- [ ] У низькій шторці заголовок картки лишається обрізаним до двох рядків, як зараз
- [ ] Перевірено на вузькому екрані (320 px) з найдовшою назвою Вправи й М'яза
