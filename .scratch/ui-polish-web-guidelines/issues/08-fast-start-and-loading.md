# 08: Швидкий старт і чесний стан завантаження

**What to build:** Застосунок відкривається швидше на слабкій мережі в залі: сторінка попередньо
завантажує модуль інтерфейсу й п'ять файлів даних, не чекаючи, поки розбереться
модуль. Поки дані не прийшли, Тренер бачить «Завантаження…», а не порожній
екран. Якщо все ж зламалось, екран збою каже, що робити далі.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Модуль інтерфейсу й п'ять файлів даних попередньо завантажуються з першого HTML; у мережевій вкладці запити стартують до виконання модуля
- [x] До приходу даних заголовок показує «Завантаження…» мовою за замовчуванням; після — назву застосунку
- [x] Екран збою зберігає сире повідомлення для розробника й додає зрозумілий Тренерові наступний крок мовою за замовчуванням
- [x] Нові рядки, якщо вони потрапили у словник, є в обох мовах і проходять перевірку словника; `node --test` зелений
- [x] Перевірено з уповільненою мережею (throttling): видно «Завантаження…», перший екран з'являється швидше, ніж до змін
- [x] Перевірено збій: підмінений ідентифікатор у контенті дає екран із наступним кроком

## Comments

**Перевірка 21.09.2026.** Автоперевірка: у `<head>` 9 preload/modulepreload; `#title` у розмітці = «Завантаження…». Не перевірено: throttling, екран збою.

**Автоперевірка 21.09.2026 (headless Chrome).** Повільна мережа (затримка 300 мс, 150 КБ/с): усі 3 секунди спостереження заголовок = «Завантаження…», потім «М'язи і вправи» й 121 рядок. Запити даних і модуля стартують разом на 329-й мс, а модуль завантажується до 1530-ї, тобто дані не чекають розбору модуля. До першого екрана: 7.2 с до змін і 6.65 с після (3 прогони, стабільно ≈0.55 с виграшу; решта часу впирається в ширину каналу). Збій: недоступний файл даних дає «Не вдалося завантажити. Перезавантажте сторінку…» і сирий текст `Failed to fetch`; помилка в контенті (підмінений ідентифікатор М'яза) дає те саме речення й повідомлення для автора контенту: `Вправа "back-squat" згадує невідомий М'яз "quadricepz"`.
