# 08: Швидкий старт і чесний стан завантаження

**What to build:** Застосунок відкривається швидше на слабкій мережі в залі: сторінка попередньо
завантажує модуль інтерфейсу й п'ять файлів даних, не чекаючи, поки розбереться
модуль. Поки дані не прийшли, Тренер бачить «Завантаження…», а не порожній
екран. Якщо все ж зламалось, екран збою каже, що робити далі.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Модуль інтерфейсу й п'ять файлів даних попередньо завантажуються з першого HTML; у мережевій вкладці запити стартують до виконання модуля
- [ ] До приходу даних заголовок показує «Завантаження…» мовою за замовчуванням; після — назву застосунку
- [ ] Екран збою зберігає сире повідомлення для розробника й додає зрозумілий Тренерові наступний крок мовою за замовчуванням
- [ ] Нові рядки, якщо вони потрапили у словник, є в обох мовах і проходять перевірку словника; `node --test` зелений
- [ ] Перевірено з уповільненою мережею (throttling): видно «Завантаження…», перший екран з'являється швидше, ніж до змін
- [ ] Перевірено збій: підмінений ідентифікатор у контенті дає екран із наступним кроком
