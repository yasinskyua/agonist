# 09: Іконка й колір смуги браузера

**What to build:** Застосунок має власну іконку у вкладці й на домашньому екрані, а смуга
браузера збігається з кольором фону застосунку, тож він виглядає цілісним. Проста
іконка (назва чи ініціал у кольорах Ролей); окремий дизайн сюди не входить.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] У вкладці браузера й на домашньому екрані iOS/Android видно іконку, а не знімок сторінки чи літеру
- [ ] Смуга браузера на Android і Safari має колір фону застосунку
- [ ] Немає 404 на запит іконки в мережевій вкладці
- [ ] Іконка читається в розмірі вкладки (16–32 px) і на домашньому екрані (180 px)
- [ ] Жодного нового залежного пакета чи кроку збірки
