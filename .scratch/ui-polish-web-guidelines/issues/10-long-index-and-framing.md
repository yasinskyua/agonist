# 10: Довгий індекс і кадрування фігури без ривків

**What to build:** Індекс на ~120 рядків відкривається без затримки, а під час руху шторки фігура
не перераховується з перемежуванням читання розмірів і запису: усі виміри
читаються один раз, а рамки М'язів кешуються. Зовнішня поведінка кадрування
(рамка, поле, мінімальний розмір) лишається тією самою.

**Blocked by:** None (can start immediately)

**Status:** needs-info

- [x] Невидимі рядки індексу й груп не беруть участі в розкладці (лінива розкладка); прокрутка й фокус працюють як раніше
- [x] Під час анімації шторки читання розмірів і запис кадру фігури не перемежовуються між хостами
- [x] Рамки М'язів на фігурі кешуються; кеш не застаріває, бо SVG не змінюється під час сесії
- [x] Кадрування фігури для карти, М'яза й Вправи візуально ідентичне тому, що було (порівняти скріншоти до й після)
- [ ] У профайлері браузера виміряно: розкладка під час анімації шторки не гірша за початкову, бажано краща
- [x] `node --test` зелений, тести зон тапу без змін

## Comments

**Зроблено.** `app/app.css`: `content-visibility: auto` для `#results .row`
(`contain-intrinsic-size: auto 3.7rem` ≈ реальний двохрядковий рядок). Групи не
чіпаю: їхня висота залежить від числа рядків, одна оцінка на всі давала б стрибки
смуги прокрутки. `app/ui.mjs`: `boxOn` кешує рамку кожного М'яза на фігурі
(`WeakMap` → `Map`; порожній заміряний 0 × 0, коли фігура не на екрані, не кешується
і не йде в об'єднання); `reframe` спершу читає розміри хостів і рамки М'язів
(прогріває кеш), потім пише всі `viewBox` — читання й запис не перемежовуються.

Закладка прокрутки: пропущені рядки лише «вгадані», тож повернення вглиб індексу
приземлялося б не туди. Тому на час одного кадру `#results.whole` розгортає всі
рядки, ставить `scrollTop`, а тоді невидимі знову пропускаються зі своїми справжніми
розмірами. Перевірено: прокрутка до 4000 px кроками, відкрити рядок, «Назад» —
той самий рядок на тому самому місці (числове `scrollTop` інше, бо висоти
скориговано).

Кадрування для Вправ (`ab-wheel-rollout`, `back-extension`), М'язів (`abductors`,
`biceps_brachii`) і карти збігається зі старим до останнього знака `viewBox`
(порівняно як рядки, не скріншоти). `node --test`: 51 з 51.

**Не виконано: вимір у профайлері.** У панелі Browser pane медіана кадру при зміні
висоти сцени ≈10.5 мс до й ≈10.8 мс після — шум, обмежений частотою екрана; вигоду
`content-visibility` на 121 рядку тут не виміряти. Треба перевірити на телефоні
Тренера (Safari Web Inspector → Timelines → Layout & Rendering) — перевіряє людина.
