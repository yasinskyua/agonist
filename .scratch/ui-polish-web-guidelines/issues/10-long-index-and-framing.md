# 10: Довгий індекс і кадрування фігури без ривків

**What to build:** Індекс на ~120 рядків відкривається без затримки, а під час руху шторки фігура
не перераховується з перемежуванням читання розмірів і запису: усі виміри
читаються один раз, а рамки М'язів кешуються. Зовнішня поведінка кадрування
(рамка, поле, мінімальний розмір) лишається тією самою.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Невидимі рядки індексу й груп не беруть участі в розкладці (лінива розкладка); прокрутка й фокус працюють як раніше
- [ ] Під час анімації шторки читання розмірів і запис кадру фігури не перемежовуються між хостами
- [ ] Рамки М'язів на фігурі кешуються; кеш не застаріває, бо SVG не змінюється під час сесії
- [ ] Кадрування фігури для карти, М'яза й Вправи візуально ідентичне тому, що було (порівняти скріншоти до й після)
- [ ] У профайлері браузера виміряно: розкладка під час анімації шторки не гірша за початкову, бажано краща
- [ ] `node --test` зелений, тести зон тапу без змін
