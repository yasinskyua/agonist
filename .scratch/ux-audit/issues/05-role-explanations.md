# 05: Пояснення Ролей

**What to build:** Тап по назві Ролі в легенді розкриває одне речення, що вона
означає, — на місці, без переходу; повторний тап закриває. Речення кожної з
п'яти Ролей — за визначеннями з `CONTEXT.md`, обома мовами. Легенда з
поясненнями з'являється скрізь, де Ролі названі: на сторінці Вправи (є зараз),
на сторінці М'яза й у відкритій Картці Гри (там її зараз немає) — з тих Ролей,
які на екрані справді названі. До завдання Картки Гри «Назви Агоніста вголос»
додається таке саме розкривне «Хто такий Агоніст?». Розкриття — нативним
елементом, без власного JS. Звіт аудиту: К3.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Тап по Ролі в легенді відкриває й закриває її речення на місці
- [ ] Речення п'яти Ролей узгоджені з визначеннями в `CONTEXT.md`
- [ ] Сторінка М'яза має легенду з тих Ролей, які М'яз має у своїх Вправах
- [ ] Відкрита Картка Гри має легенду з Ролей свого Розподілу
- [ ] Картка Гри до відкриття має «Хто такий Агоніст?» з реченням про Агоніста
- [ ] Розкриття доступне з клавіатури й читається VoiceOver як розкривний елемент
- [ ] Тести екранів: легенда містить речення кожної показаної Ролі, і лише показаних
- [ ] Нові написи є обома мовами
- [ ] Перевірка на iPhone: Вправа, М'яз, Картка Гри
