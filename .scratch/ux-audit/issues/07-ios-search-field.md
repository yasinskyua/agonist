# 07: Поле пошуку як в iPhone

**What to build:** Поле пошуку на головній виглядає як пошук iPhone:
заокруглене поле з фоном, лупа ліворуч, підказка, ✕ очищення всередині. Зараз
це великий сірий напис над лінією, схожий на заголовок. Поки поле у фокусі або
має текст, праворуч з'являється «Скасувати»: очищає запит, прибирає клавіатуру
й повертає мапу, якщо її згорнув пошук. Згортання мапи з тікета 01 не
змінюється. Звіт аудиту: В4.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Поле має лупу, заокруглену форму й фон; підказка читається
- [ ] ✕ очищення всередині поля з'являється лише з текстом
- [ ] «Скасувати» з'являється при фокусі або з текстом і зникає після тапу
- [ ] «Скасувати» очищає запит, прибирає клавіатуру й повертає згорнуту пошуком мапу; мапа, схована самою людиною, лишається схованою
- [ ] Поле не збільшує сторінку при фокусі на iOS (розмір тексту не менший за 16 px)
- [ ] Зона натискання «Скасувати» й ✕ — не менше 44 pt
- [ ] Нові написи є обома мовами
- [ ] Перевірка на iPhone: фокус, набір, ✕, «Скасувати»
