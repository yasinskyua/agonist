# 07: Поле пошуку як в iPhone

**What to build:** Поле пошуку на головній виглядає як пошук iPhone:
заокруглене поле з фоном, лупа ліворуч, підказка, ✕ очищення всередині. Зараз
це великий сірий напис над лінією, схожий на заголовок. Поки поле у фокусі або
має текст, праворуч з'являється «Скасувати»: очищає запит, прибирає клавіатуру
й повертає мапу, якщо її згорнув пошук. Згортання мапи з тікета 01 не
змінюється. Звіт аудиту: В4.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] Поле має лупу, заокруглену форму й фон; підказка читається
- [x] ✕ очищення всередині поля з'являється лише з текстом
- [x] «Скасувати» з'являється при фокусі або з текстом і зникає після тапу
- [x] «Скасувати» очищає запит, прибирає клавіатуру й повертає згорнуту пошуком мапу; мапа, схована самою людиною, лишається схованою
- [x] Поле не збільшує сторінку при фокусі на iOS (розмір тексту не менший за 16 px)
- [x] Зона натискання «Скасувати» й ✕ — не менше 44 pt
- [x] Нові написи є обома мовами
- [ ] Перевірка на iPhone: фокус, набір, ✕, «Скасувати»

## Comments

**Зроблено 23.09.2026.** `app/screens.mjs`: поле — заокруглений `.field` з лупою й ✕
всередині, «Скасувати» поруч; `app/ui.mjs`: `cancelSearch` очищає запит, знімає
фокус і через `search('')` повертає мапу лише якщо її згорнув пошук (сховану
людиною не чіпає). Кнопка не забирає фокус на `pointerdown`, тож не зникає до
кліку. Шрифт поля `max(1rem, 16px)`, ✕ і «Скасувати» — 44 px. Перевірено у
вбудованому браузері 390 × 700 обома мовами.

Відоме: Tab з порожнього поля з апаратної клавіатури ховає «Скасувати» — для
дотику не важливо.

Лишається людині: перевірка на iPhone (фокус, набір, ✕, «Скасувати»).
