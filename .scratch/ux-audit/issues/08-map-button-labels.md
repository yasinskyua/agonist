# 08: Кнопки мапи з підписами

**What to build:** Кнопки на мапі, чия дія неочевидна зі значка, отримують
видимий короткий підпис словом: «Сховати мапу» (зараз «^») і «Усе тіло»
(з'являється після збільшення). «+», «−» і «на весь екран» лишаються значками —
вони однозначні. Кількість кнопок не зростає, і мапа не втрачає помітно
місця. Звіт аудиту: В3.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] «Сховати мапу» має видимий підпис словом
- [x] «Усе тіло» має видимий підпис словом
- [x] «+», «−» і «на весь екран» лишаються значками з назвою для VoiceOver
- [x] Підписи не накривають фігуру сильніше, ніж зараз кнопки; на iPhone SE вміщуються
- [x] Нові написи є обома мовами, англійські не ламають розкладку
- [ ] Перевірка на iPhone SE і iPhone 13: головна, М'яз, Вправа

## Comments

Зроблено: «Сховати мапу» — значок + слово, «Усе тіло» — слово. На мапі на сторінці «Усе тіло»
стоїть над парою «−»/«+» (поруч з «Сховати мапу» не вміщалось на 320 px); на весь екран — поруч
з «−»/«+». Перевірено в емуляції 320 і 390 px, обома мовами; лишилась перевірка на самому iPhone.
