# 09: Шеврони в рядках-посиланнях

**What to build:** Кожен рядок, що відкриває сторінку М'яза чи Вправи, має
«›» праворуч, після кількості вправ чи Ролі, — як рядки-посилання в
застосунках iPhone. Зараз рядки схожі на текст, і що вони натискаються, видно
лише після тапу. Рядки, що сторінку не відкривають (вибір Теми, навігація
Конспекту, варіанти Тесту), шеврона не мають. Звіт аудиту: В5.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Кожен рядок-посилання на М'яз чи Вправу має «›» праворуч
- [ ] Рядки-кнопки шеврона не мають
- [ ] Шеврон не зсуває кількість вправ чи Роль і не переносить їх на новий рядок без потреби
- [ ] VoiceOver не читає шеврон окремо
- [ ] Тести екранів: рядки-посилання мають шеврон, рядки-кнопки — ні
- [ ] Перевірка на iPhone: індекс, пошук, М'яз, Вправа
