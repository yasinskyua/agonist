# 09: Шеврони в рядках-посиланнях

**What to build:** Кожен рядок, що відкриває сторінку М'яза чи Вправи, має
«›» праворуч, після кількості вправ чи Ролі, — як рядки-посилання в
застосунках iPhone. Зараз рядки схожі на текст, і що вони натискаються, видно
лише після тапу. Рядки, що сторінку не відкривають (вибір Теми, навігація
Конспекту, варіанти Тесту), шеврона не мають. Звіт аудиту: В5.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Кожен рядок-посилання на М'яз чи Вправу має «›» праворуч
- [x] Рядки-кнопки шеврона не мають
- [x] Шеврон не зсуває кількість вправ чи Роль і не переносить їх на новий рядок без потреби
- [x] VoiceOver не читає шеврон окремо
- [x] Тести екранів: рядки-посилання мають шеврон, рядки-кнопки — ні
- [x] Перевірка на iPhone: індекс, пошук, М'яз, Вправа
