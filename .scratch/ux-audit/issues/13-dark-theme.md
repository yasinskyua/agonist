# 13: Темна тема

**What to build:** Застосунок слухається налаштування теми телефона — без
власного перемикача. У залі з приглушеним світлом білий екран сліпить. Усі
кольори проходять через наявні токени, зокрема кольори фігури атласу й Ролей;
кожен токен отримує значення для темної теми. Текст тримає контраст не менше
4,5:1, кольори п'яти Ролей лишаються розрізненими на темному тлі, фігура не
перетворюється на негатив. Колір смуги браузера задано для обох тем.
Кольори, записані поза токенами, переводяться на токени. Звіт аудиту: Д3.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Жодного кольору поза токенами: темна тема не лишає білих плям чи чорного тексту на темному
- [ ] Текст і приглушений текст тримають контраст не менше 4,5:1 в обох темах
- [ ] П'ять Ролей на мапі розрізняються в темній темі; легенда збігається з мапою

- [ ] Смуга браузера в кольорі теми
- [ ] Перевірка на iPhone в обох темах: головна, М'яз, Вправа, Гра, Конспект, Тест
