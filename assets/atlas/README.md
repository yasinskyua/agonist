# Атлас: два SVG

Тут лежать `front.svg` і `back.svg` — зовнішня мускулатура, чоловіча фігура,
і згенерований з них `muscle-ids.json`.

Джерело й ліцензія — `CREDITS.md` у корені. Вибір саме цього атласу і
відхилені альтернативи — `docs/adr/0003-body-map-artwork.md`.

## Експорт (крок для людини, один раз)

Figma Community не віддає файл по URL: його треба скопіювати собі в акаунт і
експортувати вручну.

1. Відкрити <https://www.figma.com/community/file/1320468164820924031/human-anatomy-component-system>
   і натиснути **Open in Figma** (потрібен акаунт Figma, безкоштовного досить).
2. Знайти фрейм зовнішньої мускулатури — **anterior** (вид спереду).
3. У правій панелі **Export** вибрати формат **SVG**.
4. Увімкнути **Include "id" attribute** — без цієї галочки Figma не запише
   латинські імена шарів, і атлас лишиться без словника. Це єдина
   налаштовувана річ, яку тут можна зіпсувати.
5. Зберегти як `assets/atlas/front.svg`.
6. Повторити кроки 2–5 для **posterior** (вид ззаду) → `assets/atlas/back.svg`.
7. Перевірити й згенерувати перелік:

   ```bash
   node tools/atlas-ids.mjs
   ```

Скрипт падає з назвою проблеми, якщо у файлі є вбудований растр, текст,
залежність від шрифту або зовнішнє посилання — усе це в атласі неприпустиме:
підсвічування працює зміною `fill` за `id`, а додаток не робить мережевих
запитів.
